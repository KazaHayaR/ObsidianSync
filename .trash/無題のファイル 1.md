# {{date:gggg-'W'ww}}（Weekly）

> [!info] 使い方（要約の作り方）
> 1. 下の **「今週の本文（要約用コーパス）」** に表示されたテキストのうち、`=== WEEKLY_CORPUS START ===` 〜 `=== WEEKLY_CORPUS END ===` の**中身をすべて選択**します。
> 2. Obsidian のコマンドパレットから **Text Generator: Run Template** を実行し、別途作成した「Weekly 要約テンプレ」を選びます（テンプレ内で `{{selection}}` を使用）。
> 3. 生成された要約をこのノートの所定の場所に貼り付けます。

## 今週の一覧
```dataview
TABLE file.day AS 日付, dateformat(file.day, "cccc") AS 曜日
FROM "DailyNote"
WHERE file.day >= date(this.week_start) AND file.day <= date(this.week_end)
SORT file.day ASC
```
